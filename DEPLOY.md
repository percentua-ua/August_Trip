# Як опублікувати карти на URL, який можна дати команді

⚠️ **Не пушьте це в `symsphere-symcad-translation-layer`** — це робочий репозиторій. Публікація зробила б вихідний код доступним усьому світу. Для сайту використовуйте окремий особистий репозиторій.

Готовий сайт лежить у папці **`trip-site/`** — ~900 КБ, без збірки, без залежностей. Українські карти коректно виглядають і на телефоні, тож окремої мобільної версії немає:

| Файл | Що це |
|---|---|
| `index.html` | головна сторінка, українська за замовчуванням, перемикач УКР/ENG |
| `day1…day5-aug2X-map.html` | п'ять днів українською (те, що відкриває `index.html`) |
| `day1…day5-aug2X-map-en.html` | ті самі п'ять днів англійською |
| `budapest-vienna-plan-aug20-23.md`, `*.kml`, `*.csv`, `day1-aug20-map.pdf` | текстовий план, файли для Google Maps, PDF |
| `.nojekyll` | вимикає обробку Jekyll на GitHub Pages |

## Варіант A — GitHub Pages (безкоштовно, постійний URL)

### 1. Створіть репозиторій

Відкрийте <https://github.com/new> **під особистим акаунтом** (не під організацією):

- Назва: `budapest-vienna-trip`
- Видимість: **Public** — Pages для приватних репозиторіїв доступні лише на GitHub Pro/Team
- README та .gitignore не додавайте

### 2. Завантажте файли

**Через браузер (без git):** на сторінці нового репозиторію натисніть **uploading an existing file**, перетягніть **вміст** папки `trip-site` (усі файли, не саму папку) → **Commit changes**.

**Через git:**

```bash
cd "C:\Users\v.seliverstova\Desktop\SymboticHub\symsphere-symcad-translation-layer\trip-site"

git init
git add .
git commit -m "Trip maps site"
git branch -M main
git remote add origin https://github.com/<ВАШ-ЛОГІН>/budapest-vienna-trip.git
git push -u origin main
```

Якщо для особистого акаунта налаштований SSH-ключ, беріть адресу `git@github.com:<ВАШ-ЛОГІН>/budapest-vienna-trip.git`.

### 3. Увімкніть Pages

Репозиторій → **Settings** → **Pages** → *Source*: **Deploy from a branch** → бранч `main`, папка `/ (root)` → **Save**.

Через ~1 хвилину сайт живий:

```
https://<ВАШ-ЛОГІН>.github.io/budapest-vienna-trip/
```

Це і є посилання для команди — жодного логіну, жодних запрошень. Окремий день, якщо потрібно надіслати точково:

```
https://<ВАШ-ЛОГІН>.github.io/budapest-vienna-trip/day3-aug22-map.html
https://<ВАШ-ЛОГІН>.github.io/budapest-vienna-trip/day3-aug22-map-en.html
```

### 4. Оновлення

```bash
cd trip-site
git add . && git commit -m "update" && git push
```

Оновлюється за 30–60 секунд. Через браузер: у репозиторії відкрийте файл → олівець → **Commit changes**, або знову **Add file → Upload files** і підтвердіть заміну.

### Що варто знати

- **Public означає public.** Будь-хто з посиланням побачить сторінку, і Google може її проіндексувати. Для туристичних карт це нормально — але не додавайте туди номери бронювань, паспортні дані чи коди від житла.
- Якщо потрібно, щоб сторінку не індексували, додайте файл `robots.txt` із рядками `User-agent: *` та `Disallow: /`.
- Приватний репозиторій + Pages = потрібен GitHub Pro (або дивіться варіант C з паролем).

## Варіант B — Netlify Drop (найшвидше, ~20 секунд, без git)

1. Відкрийте <https://app.netlify.com/drop>
2. Перетягніть на сторінку **усю папку `trip-site`**
3. Одразу отримуєте адресу типу `https://random-name-123.netlify.app`

Реєстрація не потрібна для першого завантаження; увійдіть, якщо хочете залишити посилання назавжди та перейменувати його. Найкращий варіант, якщо лінк потрібен «просто зараз».

---

## Варіант C — Cloudflare Pages (швидко в Європі, можна пароль)

1. <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Pages**
2. **Upload assets** (без git) або підключіть репозиторій із варіанта A
3. Build command: *немає*, output directory: `/`
4. Адреса: `https://<проєкт>.pages.dev`

На безкоштовному тарифі через **Cloudflare Access** можна закрити сайт паролем або списком email — єдиний із трьох варіантів, де доступ можна обмежити безкоштовно.

## Якщо готові платити

Чесно: для 900 КБ статики платити майже нема за що — усі три варіанти вище тримають цей сайт на безкоштовному тарифі без обмежень, які ви відчуєте. Ось що реально можна купити і чи варто.

| Що | Ціна | Чи варто |
|---|---|---|
| **Свій домен** (`nazar.trip` абощо) через Cloudflare Registrar або Namecheap | ~$10–14 / рік | Єдина покупка з реальним сенсом: коротке посилання, яке легко продиктувати вголос. Працює і з GitHub Pages, і з Cloudflare Pages. |
| **GitHub Pro** | $4 / міс | Дає Pages з **приватного** репозиторію — але сам сайт усе одно лишається публічним. Приватний доступ до сторінки — це лише GitHub Enterprise. Не беріть заради цього. |
| **Netlify Pro** | $19 / міс | Пароль на сайт «з коробки», в один перемикач. Але те саме дає Cloudflare Access безкоштовно. |
| **Cloudflare Zero Trust** | безкоштовно до 50 користувачів | Пароль / доступ за списком email. Це і є правильний варіант, якщо не хочете, щоб сторінку бачив хтось сторонній. |

**Рекомендація:** візьміть домен (~$12/рік) і залиште хостинг на Cloudflare Pages з безкоштовним Access. Разом — вартість однієї кави на рік і приватний, короткий URL.

## Далі — на телефони команди

Надішліть URL у чат. Кожен відкриває його в Safari або Chrome → **Поділитися / меню** → **На екран «Домів»**. Далі сайт відкривається як застосунок, а всі п'ять днів — в один дотик.

Інтернет потрібен лише для мапи вулиць: пункти, маршрути, ціни й попередження зашиті в самі файли. Якщо в роумінгу зв'язок ненадійний — перед виїздом відкрийте потрібні дні один раз (сторінки закешуються) або зробіть скриншоти карт.
